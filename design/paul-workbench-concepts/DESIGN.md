# Design System: Paul工作台候选界面画廊

## Overview

**Creative North Star: "五个独立工作台，一条连续创作链路"**

本文件记录 index.html 已实现的中性浅色画廊，以及五个互相独立的候选视觉系统。五案状态均为「未批准」；默认显示方案 4 只是预览初始值，不是生产主题选择。生产应用本轮仅变更名称，不能把本文件当作生产改版授权。

用户确认的工作优先级为下载 → 转录 → 文案 → 配音。各案保留四步入口，并用不同空间结构表达同一创作链路。标题、文稿、评分、耗时、波形和任务结果均为示例；这些视觉证据不构成实际性能或能力承诺。

以上名称是交付内容的描述性索引，不是新增品牌承诺或已获批准的设计方向。依据：`../../PRODUCT.md`、`DIRECTION.md`、`index.html` 的 CSS 与事件处理。扫描模式记录已实现内容；未向用户新增一轮视觉选择。

**Key Characteristics:**
- 中性画廊不偏袒任何候选方案。
- 五案独立命名、独立颜色和布局，不拼成一个生产系统。
- 原文、精选、组稿、配音之间的上下文可辨认。

## Colors

前言中的 token 值来自实际 CSS；`c1`–`c5` 对应五案。`gallery-*` 只属于方案选择器外壳，不属于任一候选应用。

### Primary

| 状态 | 方案 | 主色 token | 使用位置 |
|---|---|---|---|
| 未批准 | 1 极简浅色 | `c1-accent` | 主操作、当前步骤、进度条与导航文字 |
| 未批准 | 2 暖纸编辑 | `c2-accent` | 朱红动作与文案工作区当前页签 |
| 未批准 | 3 深色影棚 | `c3-accent` | 暖珊瑚操作、波形与语速控件 |
| 未批准 | 4 青绿档案 | `c4-accent` | 文稿动作、选择与深绿侧栏之外的交互 |
| 未批准 | 5 流程看板 | `c5-accent` | 梅紫动作与四阶段流程 |

### Neutral

每案的 `bg`、`surface`、`rail`、`ink`、`muted`、`line`、`tint`、`button-ink` 是 `.app` 的实际变量，分别服务于画布、容器、次级区、正文、辅助文字、边界、选中底色与主按钮文字。方案 4 的 `rail` 是浅绿次级底色，真正导航侧栏另用 `c4-sidebar`；方案 5 顶部用 `c5-header`。不要用 DIRECTION.md 的摘要覆盖实际 CSS。

状态颜色是语义，不能只靠底色区分：success 对应成功/已保存，warning 对应待整理等提醒，error 对应失败；每个徽标保留文字。方案 3 为三种状态分别提供深色变体。普通状态使用该案 accent/tint。绿色小圆点只是本机状态示意，不是实时服务检测。

**The Independent Candidates Rule.** 每案只使用自己的颜色集合；画廊外壳及共有语义状态不构成候选方案混用。

## Typography

控件使用系统中文无衬线字体，前言列出完整字体栈。标题、正文、标签和按钮的层级均从 CSS 提取；字号不是未经实现的品牌规范。文章正文常规行高为 2、最大宽度为 66ch；辅助文字常见行高为 1.6–1.85。数字耗时使用 tabular-nums。

方案 2 的文章、文档标题与对读标题使用 Songti 系列衬线字体，控件继续使用无衬线。其标题为 27px，文章为 17px；方案选择器的优先级高于共有双稿区域的 15px 文章规则，因此方案 2 的双稿正文仍为 17px。方案 3 的脚本文本框为 17px、行高 2.1；默认脚本文本框为 16px。

## Layout

画廊最大宽度 1600px，常规内边距为 26px 34px 30px；方案选择器五等列。应用预览高度 728px、最小宽度 1110px；并排缩略图使用 1360×728 的源框再等比缩小。预览横向滚动，不把桌面应用伪装成已经实现的手机应用。

| 未批准方案 | 空间结构与初始工作区 | 已实现尺寸区别 |
|---|---|---|
| 1 极简浅色 | 左导航、任务表、右侧运行任务；初始为转录 | 侧栏 187px；任务区域为弹性列 + 270px；间距 22px |
| 2 暖纸编辑 | 顶部品牌，无左栏；两份原稿 + 评分列；初始为文案 | 顶栏 68px；内容内边距 27px 37px；双稿为 1fr 1fr 215px、间距 28px |
| 3 深色影棚 | 左导航、脚本与波形、右侧配音参数；初始为配音 | 配音区域为弹性列 + 255px、间距 25px；顶栏与流程条回归深色画布 |
| 4 青绿档案 | 深绿导航 + 文稿列表 + 原文 + 精选；初始为文案 | 导航 174px；资料区为 227px / 弹性列 / 230px |
| 5 流程看板 | 梅紫顶栏，无左栏；四阶段标准看板；初始为看板 | 顶栏 65px；四等列、间距 17px；每列最小高度 380px |

共有控件不是五种全新交互范式：链路条始终可进入下载素材、提取文字、精选组稿与制作配音；画廊另提供相同工作区切换供比较。现有局部 padding/gap 还包括 10、13、17、19、21、22、25、26、27、28、35、37px 等，不强行归入前言中的常用间距集合。

窗口宽度不超过 1000px 时，画廊内边距变为 20px，选择器标签精简，并排比较改为一列；不超过 620px 时，选择器改为两列，最后一案占满行，说明与工作区按钮换行。应用仍保持桌面最小宽度。`frame=1` 隐藏画廊外壳并移除预览框圆角；`overview` 只展示五案缩略总览。

## Elevation & Depth

应用内部主要依靠底色层次和 1px 边框划分区域，没有全局浮卡阴影。画廊预览框使用 `0 14px 42px #00000014`，选中的方案标签使用 `0 2px 6px #13202d0a`，临时提示使用 `0 6px 16px #0002`。这些值只用于各自当前组件，不扩展为新的全局阴影等级。

按钮仅对背景和文字颜色进行 0.15s 过渡；主按钮 hover 为 brightness(.95)。并排比较展开时可平滑滚动；系统减少动态效果设置会关闭 transition 并改用即时滚动。没有为五案新增动效路线。

## Shapes

普通按钮和表单为 6px 圆角，方案 2 按钮、input、select 为 3px；徽标 4px、步骤 5px、导航 7px、看板列和精选面板 8px、通用面板 9px、主预览框 13px。方案 2 应用外框为 5px；frame 模式外框为 0。SVG 图标采用 1.65px 描边、圆端点与圆连接，不用图标字体。

## Components

### Buttons

主操作使用对应 accent 与 button-ink，常规内边距 9px 13px、最小高度 35px。次按钮使用 surface/ink/line；quiet 是透明无边界的文字动作，icon 按钮有明确 aria-label。hover 使用 tint，主操作保留 accent 并降低亮度。焦点是 2px 实线，outline-offset 为 4px；应用内用方案 accent，画廊用 gallery-focus。disabled 保留原样式并降至 0.55 不透明度。源码没有单独的按压状态，不把自创样式当作已实现行为。

### Inputs / Fields

输入框使用 surface 背景、ink 文字、line 边框与 muted 占位文字；普通内边距 10px 12px。textarea 可纵向缩放。链接输入为空时会聚焦输入框并显示示例提示；不具备真实下载或服务端验证。模型选择为标准 select；评分模型默认「暂不选择模型」，原型不会发起调用。配音预设、语速滑块与声音参数只改变本页示例状态。

### Navigation

方案选择器是标准 button，使用 role=tab 与 aria-selected 显示选中态；四步条对当前步骤设置 aria-current=step。一般侧栏用 surface 表示当前项、accent 表示当前文字；方案 4 用 sidebar-active 与白色文字。普通导航 hover 使用 tint；方案 4 hover 使用 sidebar-active。桌面方案在小屏下继续横向滚动。

### Chips / Cards

状态徽标使用文字 + 语义颜色；筛选器用标准按钮，当前项以 surface/ink 区别。看板卡片包含文件类型、状态、标题、辅助信息和下一步按钮，是普通容器而非拖拽控件。资料列表的选中文稿保留 tint 背景；原文与精选分开显示。运行卡、任务表和进度条内容是固定示例。

### Selection → Draft → Voice

选中文字或点击示例段落会追加到内存中的精选列表，移除只改本页列表。按顺序组稿把精选以空行连接为 `draftText`，编辑组稿正文会更新该值；进入配音后 textarea 读取同一个 `draftText`，编辑配音文字也会回写该值。普通工作区切换不会故意丢弃此内存文本；重新组稿会用当前精选重新构建草稿，刷新页面会回到示例初值。页面不保存真实文稿或真实来源记录。

段落来源提示、参考评分、试听范围、生成历史、模型设置、知识库、直播录制等为说明或 toast。波形为 SVG 计算图形，没有音频播放；暂停仅切换示例任务状态。`fetch`、XHR、模型 API、文件写入及持久化存储均未接入。并排比较通过同页 URL 的 iframe 展示各案，除此以外没有后台/业务网络调用。

## Do's and Don'ts

### Do:
- Do 把五案持续标记为未批准，按用户选择再推进生产实现。
- Do 从对应方案的命名空间取色，保留文字状态与可见下一步。
- Do 保留示例说明、来源提示、键盘焦点和减少动态效果支持。

### Don't:
- Don't 把方案 4 的默认展示解释成生产批准。
- Don't 把示例评分、转录耗时、波形或按钮提示写成真实执行结果。
- Don't 在本原型接入模型、网络请求、真实文件写入或生产任务控制。
