# Paul工作台

面向视频创作者的 macOS 内容工作台，把对标选题、文案准备、拍摄、后期制作、发布与复盘串成五个阶段，并接入素材获取、本地转录、文案精选和配音。

当前源码版本：**4.3.4 / 构建 20261119.1**。基于 [Lulu](https://github.com/AidenXu-1/Lulu) 开发，沿用 [MIT 许可证](LICENSE)，原始版权声明与第三方许可完整保留。

## 当前功能

| 环节 | 能力 |
| --- | --- |
| 选题收录 | 手动选题、本地 TXT / Markdown / CSV / JSON、公开页面与使用者指定的飞书资料；预览、筛选、状态、标签和来源留存 |
| 视频拆解 | 本地视频播放、时间段标记，以及开头、内容顺序、文案、画面、剪辑、结尾六个维度的记录 |
| 素材与转录 | 音视频下载、主页采集、封面保存、直播录制与画质选择；SenseVoice Q8、Whisper、Whisper 4bit、MOSS |
| 文案 | 并排对比、逐句点选、用户指定模型评分、精选组稿，可从「视频制作」进入同一个文案项目 |
| 配音与资料 | 本地配音、文稿与音频库、Obsidian / 飞书集成、Agent CLI 和可替换配色 |

文案评分需要使用者主动选择已配置的模型连接。仅添加候选文案不会调用模型；原始文稿保留，候选副本可以单独整理。

## 本版更新：视频制作五阶段

从侧栏「视频制作」选中一个项目，按对标与选题、准备文案、拍摄、后期制作、发布与复盘记录步骤、依据与产物。记录随选题自动保存，可用「导出当前记录」生成 Markdown。拍摄、后期和发布页面用于管理素材、预览、验收和复盘记录。

「准备文案 → 商单 Brief 五步」依次提供提炼卖点、补充 IP 背景和甲方要求来筛思路、确定制作方向、写大纲、展开拍摄脚本的入口。每条卖点可保留 Brief 原句或页码、观众收益与可拍画面。

## 选题状态与飞书同步

「视频制作」支持导入预览、标题与链接列选择、来源去重、标签与状态筛选。能识别常用历史筛选状态及 Markdown 链接，保留已有记录。飞书 Docx / Wiki / Base 由使用者在运行时指定，需要配置自己的连接，也可先导出本地文件导入。

工作台将未筛选状态统一显示为「待筛」，并保留独立的「候选」。修改右侧当前选题状态后，左侧自动显示同状态选题。左侧手动筛选只影响列表。

状态同步可在「视频制作 → 同步飞书状态」连接。先安装并登录飞书 CLI（`lark-cli`），导入自己的多维表格，再粘贴包含 `table=` 的具体表链接。表需要有单选的「制作状态」列，包含「待筛」「候选」「制作中」「暂存」「已完成」「已排除」。工作台按稳定记录 ID 匹配已导入选题，只读写其制作状态。工作台保存后尝试回写，打开选题页以及运行期间每 5 分钟检查飞书。同一选题在两端分别改成不同值时会提示冲突。

视频只关联本地文件，不重复复制大文件。可按时间段记录片段作用、文案、画面、剪辑和可借鉴之处，并关联文稿库逐字稿。AI 文字拆解须选择模型并确认发送，结果先预览再追加；它不上传视频，不把逐字稿当成已观看的视频，画面与剪辑仍需结合实际视频标注。

「进入文案精选」连接对应的文案项目，保存参考副本；相同快照不重复添加，已有候选和手写稿保留。页面及弹窗沿用工作台配色，并适配 macOS 深色外观。详见 [功能说明](app/docs/features/creator-workbench.md)。

本地选题库、个人文档地址、账号连接、录音和转录结果独立存放，不属于源码仓库。源码入口不绑定任何个人资料库。

## 逐句点选组稿

「文案精选」默认并排展示候选文案，右侧常驻可编辑的新文案。点击任意一句即可按点击顺序加入右侧，直接修改措辞或继续输入；手动补写的内容保留。各篇独立滚动，也支持拖动选段和切换单篇编辑。

已选句子保留来源和原始文字，重复句子按原文位置分别记录。「句子来源与排序」可展开查看；使用片段重新组稿会保留上一版正文。此前的「创作中枢」应用与工作台图标继续保留。

## 新增：候选文案 CLI

`20261115.1` 新增 `editorial.list`、`editorial.show`、`editorial.candidate`、`editorial.create` 和 `editorial.add-candidate`。可以查询与新建选题，直接添加正文，或把版本匹配的现有文稿复制进「文案精选 → 候选文案」。

写入使用版本检查与持久化请求回执，重复请求不会重复添加。界面自动同步新增内容，并保留本地正在编辑的正文、精选片段和组稿。

调用前按 [独立 Agent Skill](agent-skill/README.md) 校验实际安装，再查询 `capabilities` 和 `workspace tools catalog`；只有已安装 App 返回可用的接口才能执行。详细参数见 [文案精选调用说明](agent-skill/lulu-agent/references/workspace.md)。

## 运行与构建

目标环境：Apple Silicon、macOS 15 或更新版本。完整依赖、构建入口和校验流程见 [BUILDING.md](BUILDING.md)。

源码目录：`app/src` 为产品实现，`app/native` 为原生通信，`app/packaging` 为构建和包体校验，`app/tests` 为测试，`agent-skill` 为独立技能。

应用显示名称为「Paul工作台」；内部包路径保留 `/Applications/Lulu.app`，CLI 入口为 `/Applications/Lulu.app/Contents/MacOS/lulu-agent-cli`，以兼容安装校验、数据和现有调用方。

当前提交提供源码。本版通过 1577 项完整产品能力检查，并完成原生界面与本机安装验证。安装包以本仓库实际发布的 Release 为准；上游 Lulu 安装包不包含这里新增的定制功能。
