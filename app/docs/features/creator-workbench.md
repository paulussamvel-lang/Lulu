# 选题、对标拆解与文案

工作流：**选题收录与筛选 → 对标视频拆解 → 文案精选**。采用现有原生控件和配色，不迁移框架。

## 选题收录与筛选

侧栏「选题与拆解」支持手动选题、本地 TXT / Markdown / CSV / JSON / 字幕文件、公开文字页面，以及用户指定的飞书 Docx / Wiki / Base。导入先展示正文预览；表格可选择标题列和链接列，再勾选需要的记录。飞书复用用户在设置中配置的连接，只执行 GET。尚未配置连接时，可先把资料导出成本地文件导入。页面登录、私有网站或纯视频页面不能保证直接读取正文，可记录链接再用内容提取。

状态包括待筛选、候选、确定制作、暂存、已完成、不采用；不采用需填写理由，不删除资料。表格中的常用状态与标签一并保留，Markdown 形式的链接会提取成页面地址。记录目标观众、具体痛点、观众收获、自己的切入点、证据、制作条件。可按状态筛选或全文搜索。每个选题可补充多个参考链接。

## 视频拆解

本地视频关联原文件路径，不额外复制。播放器支持播放、暂停、拖动时间轴，标记和修改时间段，双击片段定位。六个维度为开头、内容顺序、文案、画面、剪辑、结尾；每段可记录文案、画面、剪辑和可借鉴方式。逐字稿可从现有文稿库追加副本，也能粘贴。

AI 文字拆解是可选辅助：用户选择已配置的模型，确认发送文字，预览结果后追加。它不上传视频；缺少画面、剪辑记录时强制标记待补充，不把逐字稿当成已观看的视频。生成不执行工具，不自动写入。取消、错误和资料变化保留原笔记。

## 接入文案精选

「进入文案精选」按选题 ID 连接一个文案项目；将当前选题与拆解作为参考候选副本。相同快照不重复添加，拆解变化后生成新参考副本；已有候选、组稿正文与原文稿保留。继续使用并排对比、选句、手工编辑和模型评分。

## 数据与发布边界

- 本机数据：应用数据目录 `creator-workbench/topics.sqlite3`，逐条修订号避免覆盖并发编辑，批量导入事务提交；导入保留来源、时间与文档修订。
- 去重：支持作品 ID、来源记录 ID 和普通来源地址。重复导入跳过已有内容，不静默刷新或覆盖。
- 源码及公开示例不含任何个人文档地址、表格标识、账号或实际内容。来源在运行时由用户指定，仅保存在本机数据库和用户主动导出的文件中。不得将运行数据加入发布包或 Git 历史。
- 导入不回写远端、不自动抓取附件、不启动转录，也不下载模型。下载、转录继续使用现有内容提取入口，由用户选择执行。
- 安装仍需等待所有转录、录制和生成任务完成；读取或保存未完成时阻止退出。
